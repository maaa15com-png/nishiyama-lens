# NISHIYAMA LENS

> 西山公園を、あなたの「LENS」で見つけよう。

NISHIYAMA LENSは、福井県鯖江市の西山公園を舞台に、
一人ひとりに合った「行く理由」と「楽しみ方」を見つけるWebアプリです。

## 🌳 About

西山公園には、レッサーパンダ、つつじ、紅葉、写真スポット、
家族で楽しめる場所など、さまざまな魅力があります。

NISHIYAMA LENSでは、

「誰と行く？」
「何を楽しみたい？」

といった簡単な質問から、
その人に合った西山公園の楽しみ方を提案します。

旅行前に西山公園を「発見」し、
現地では自分のLENSを通して公園を楽しみ、
帰ったあとには「別の季節にも行ってみたい」と思える。

そんな体験を目指しています。

## 🔍 LENS

「誰と行くか」×「何を楽しむか」を組み合わせて、
自分に合った西山公園の楽しみ方を見つけます。

例：

- FAMILY × PANDA
- COUPLE × PHOTO
- SOLO × RELAX
